# Star Wars Encyclopedia

Browse the Star Wars universe – films, people, planets, species, starships and vehicles – with list and detail pages, search and pagination. Data comes from a Star Wars REST API.

## Tech stack

React, TypeScript, Vite, React Router, React Bootstrap, Axios, SCSS

## Getting started

```bash
cp .env.example .env   # set VITE_BASE_URL to the Star Wars API
npm install
npm run dev
```
